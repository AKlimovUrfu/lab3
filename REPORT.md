# Отчёт по лабораторной работе №3: Линейные модели

## 1. Данные и подготовка

### Линейная регрессия (Student_Performance.csv)
- **Размер выборки:** 1000 строк, 8 признаков
- **Целевая переменная:** Performance Index (непрерывная)
- **Подготовка данных:**
  - Категориальные признаки кодировались через one-hot encoding
  - Данные масштабировались (вычитание среднего, деление на стандартное отклонение)
  - Разбиение на train/test: 80%/20%, random_state=42

### Логистическая регрессия (german.csv)
- **Размер выборки:** 1000 строк, 20 признаков
- **Целевая переменная:** Creditability (бинарная: 0 или 1)
- **Подготовка данных:**
  - Файл использует разделитель `;`, данные уже числовые
  - Масштабирование через StandardScaler
  - Разбиение на train/test: 80%/20%, random_state=42

## 2. Гипотезы и эксперименты

### Гипотеза 1: Градиентный спуск сойдётся к оптимальным весам
- **Параметры обучения:**
  - Learning rate: 0.05 (регрессия), 0.1 (классификация)
  - Количество эпох: 800 (регрессия), 1000 (классификация)
- **Результат:** Функция потерь монотонно убывала, модель обучилась успешно

### Гипотеза 2: Собственная логистическая регрессия покажет результаты, сопоставимые со sklearn
- **Эксперимент:** Сравнение с LogisticRegression, DecisionTreeClassifier, KNeighborsClassifier из sklearn
- **Результат:** Собственная модель показала конкурентоспособные метрики

## 3. Метрики

### Линейная регрессия
- **MSE на тестовой выборке:** 4.1823

### Классификация
Точные значения всех метрик (ROC-AUC, Accuracy, Precision, Recall, F1) для всех четырёх моделей сохранены в файле `experiment_results.json`.

## 4. Выводы

1. **Реализация с нуля работает корректно:** Собственные модели линейной и логистической регрессии, реализованные через пакетный градиентный спуск, показывают результаты, сопоставимые с готовыми реализациями из sklearn.

2. **Важность масштабирования:** Standardization критически важен для сходимости градиентного спуска. Без масштабирования learning rate пришлось бы подбирать индивидуально для каждого признака.

3. **Сравнение моделей:**
   - Логистическая регрессия показывает стабильные результаты
   - Decision Tree может переобучаться на маленьких выборках
   - KNN чувствителен к выбору k и масштабированию признаков

4. **Интерпретируемость:** Линейные модели позволяют анализировать важность признаков через веса (weights), что невозможно для деревьев и KNN.

## 5. Воспроизводимость

- **Фиксированный random_state=42** при разбиении данных обеспечивает воспроизводимость результатов
- **Фиксированные гиперпараметры** (learning_rate, epochs) задокументированы в коде
- **Все результаты** сохранены в `experiment_results.json` для автоматической проверки
- **Код** полностью детерминирован: при повторном запуске с теми же данными результаты будут идентичны
