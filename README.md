# Лабораторная работа №3. Линейные модели и градиентный спуск

Цель — самостоятельно реализовать линейную регрессию и бинарный логистический
классификатор, обучаемые градиентным спуском, а затем сравнить их с готовыми
неансамблевыми моделями.

Исходные ноутбуки сохранены в репозитории как материал для экспериментов.
Сдаваемая реализация находится в `linear_models.py`. Не меняйте файлы
`grader_contracts`, имена функций, обязательный первый параметр и аннотации
возврата.

## Часть 1. Собственные модели

Реализуйте `train_linear_regression` и `train_logistic_classifier`.

Обе функции получают признаки и target в dataclass-контракте. Можно добавлять
вспомогательные классы, методы и необязательные параметры. Используйте NumPy и
градиентный спуск, а не готовую `LinearRegression` или `LogisticRegression` для
этих двух контрактных функций.

Для регрессии:

- прогноз имеет вид `X @ w + b`;
- оптимизируйте MSE;
- верните веса, bias, историю функции потерь и прогнозы на переданных данных.

Для классификации:

- используйте сигмоиду и бинарную кросс-энтропию;
- `probabilities` должны лежать в диапазоне от 0 до 1;
- `predictions` — бинарные метки по порогу 0.5;
- верните историю BCE.

## Часть 2. Эксперименты

На `Student_Performance.csv` проведите эксперимент с регрессией, на
`german.csv` — с классификацией. Нормализуйте признаки, разумно выберите
learning rate и число эпох. В отдельном ноутбуке или скрипте сравните готовые
Logistic Regression, Decision Tree и KNN. Ансамбли в этой лабораторной не
используются.

## Обязательный отчёт `REPORT.md`

Добавьте в корень репозитория Markdown-файл `REPORT.md` со следующими разделами:

1. `## Данные и подготовка` — какие признаки и преобразования использованы;
2. `## Гипотезы и эксперименты` — что меняли, зачем и какие варианты сравнили;
3. `## Метрики` — таблица с MSE для регрессии и как минимум accuracy, ROC-AUC,
   precision, recall, F1 для классификации; укажите, на каком split получены
   значения;
4. `## Выводы` — что сработало, что не сработало и почему;
5. `## Воспроизводимость` — random seed, версии библиотек при необходимости и
   команда/ноутбук, которым можно повторить эксперимент.

Не вставляйте только итоговые цифры: отчёт должен показывать ход поиска
решения. LLM-рецензент проверит понимание именно линейной и логистической
регрессии, исходя из вашего кода и отчёта, и может задать до двух вопросов по
каждой секции в одном раунде.

Разрешены `numpy`, `pandas`, `scikit-learn`, `scipy`, `matplotlib`, `seaborn`,
`statsmodels` и стандартная библиотека. Готовые модели разрешены в
экспериментальной части, но не вместо двух собственных контрактных реализаций.
